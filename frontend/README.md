# School Ecosystem Dashboard

## Run locally

Requirements: Node.js 20.19 or newer.

```powershell
cd "C:\Users\hp\OneDrive\Desktop\School EcoSystem\frontend"
npm install
npm run dev
```

Open the local URL printed by Vite (normally `http://localhost:5173`).

To create and preview a production build:

```powershell
npm run build
npm run preview
```

The dashboard currently uses sample data in the frontend. It is not connected to the Laravel backend yet.
